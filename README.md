# Care Passport

Care Passport 프로젝트 소스코드 저장소입니다.

## 구성

| 폴더 | 내용 |
|---|---|
| [`frontend/`](./frontend) | Expo/React Native 앱 |
| [`backend/`](./backend) | Spring Boot API 서버 |
| [`AI/`](./AI) | AI 서버 3종 (하자 탐지, AR 인식, 일련번호 OCR) |

각 폴더의 README/DEPLOY.md에 실행·배포 방법이 있습니다.

## APK

[mcm-care-preview.apk](./mcm-care-preview.apk)는 초기 데모 버전입니다 — 최신 빌드는 별도로 공유됩니다.
"출처를 알 수 없는 앱" 설치를 허용해야 할 수 있습니다.
